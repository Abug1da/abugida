# Abugida

Free Amharic learning site (theabugida.org). This branch (`rebuild`) is a from-scratch rebuild; the previous Vite + Firebase app and its content engine are on `content-engine`.

## Stack

- **Next.js 16** (App Router) + **Tailwind v4** + **shadcn/ui** (Base UI)
- **Cloudflare Workers** via [OpenNext](https://opennext.js.org/cloudflare)
- **D1** (SQLite) through **Drizzle ORM**
- **Better Auth** (email + password), sessions stored in D1
- **Bun** for installs and scripts

## Getting started

```sh
bun install
cp .dev.vars.example .dev.vars   # then set BETTER_AUTH_SECRET: openssl rand -base64 32
bun run db:migrate:local         # creates the local D1 database in .wrangler/
bun run dev                      # http://localhost:3000
```

`bun run preview` builds for Workers and serves it locally on the real Workers runtime (port 8787).

## Database

- Schema lives in `src/db/`. `auth-schema.ts` is generated by Better Auth (`bun run auth:generate`); put app tables in their own files and export them from `schema.ts`.
- After a schema change: `bun run db:generate` writes SQL to `drizzle/`, then `bun run db:migrate:local` (or `:remote`) applies it.
- Server code gets the database with `getDb()` from `@/db` and the session with `getSession()` from `@/lib/auth/server`. Both are per-request because D1 is only reachable through the request's Cloudflare env.

## Before the first deploy

1. `bunx wrangler login`
2. `bunx wrangler d1 create abugida` and paste the id into `wrangler.jsonc` (it is a placeholder now)
3. `bunx wrangler secret put BETTER_AUTH_SECRET` and set `BETTER_AUTH_URL` to the production URL
   (leave `BETTER_AUTH_TRUSTED_ORIGINS` unset in production). Redirect `www` to the apex domain at Cloudflare,
   in front of the Worker, or sign-in from `www` fails Better Auth's origin check.
4. `bun run db:migrate:remote`, then `bun run deploy`

Password hashing needs more CPU than the Workers free plan allows per request, so plan on the $5/month Workers Paid plan.
